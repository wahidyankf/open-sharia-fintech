# MEDIUM-Confidence Subjective Checks

These categories always route to manual review — never auto-apply.

## 1. Narrative Flow Quality

**What checker reports**: section too list-heavy (needs narrative), abrupt transition between
sections, missing explanations or context.

**Why MEDIUM**: subjective assessment of writing quality; multiple valid narrative structures;
requires human judgment on pedagogical effectiveness.

## 2. Diagram Placement Suggestions

**What checker reports**: section needs a diagram (flowchart, architecture, sequence), or the
diagram should move earlier/later.

**Why MEDIUM**: diagram necessity is subjective; placement depends on pedagogical strategy;
visual-aid effectiveness varies by learner.

## 3. Content Balance Assessment

**What checker reports**: too much theory, not enough practice; examples insufficient; hands-on
elements missing.

**Why MEDIUM**: balance depends on tutorial type and audience; "sufficient" is subjective;
pedagogical approach varies.

## 4. Writing Style Critiques

**What checker reports**: writing too dry (needs more engaging voice), inconsistent tone, voice
not conversational enough.

**Why MEDIUM**: writing style is subjective; different authors have different voices;
effectiveness varies by audience.

**Action for all four**: skip the fix, flag for manual review.
