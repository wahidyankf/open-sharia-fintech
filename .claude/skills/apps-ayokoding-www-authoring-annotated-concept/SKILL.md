# ayokoding-www Authoring: Annotated-Concept Tutorials

Methodology for authoring concept-centric worked-example tutorials (and the leadership no-code
sub-mode) for `apps/ayokoding-www/`, at equal annotation density to By Example.

1. [When to Use, Mode Selection, and Requirements](reference/01-mode-selection-and-requirements.md)
   — when to use this agent, determining standard vs. no-code sub-mode, and the requirements for
   each.
2. [Worked-Example Structure, Diagrams, Integration](reference/02-structure-diagrams-integration.md)
   — the shared worked-example/scenario structure, diagram requirements, and ayokoding-web
   integration.
3. [Workflow and Quality Standards](reference/03-workflow-and-quality.md) — the 7-step content
   creation workflow and the quality-standards checklist.

## Core Principles

- **Pick the mode first** — standard (code-bearing) vs. no-code sub-mode (leadership/governance) is
  a per-topic decision made before writing any content.
- **Floors, not caps** — 45-60 worked examples (or 20-30 scenarios) is a minimum; exceed it when the
  subject genuinely demands more.
- **Equal density to By Example** — the 1.0-2.25 annotation ratio applies identically.
