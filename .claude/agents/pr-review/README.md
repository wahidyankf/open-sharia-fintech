# PR Review

- [Pr Review Architecture Maker](./pr-review-architecture-maker.md) — Execution-grade PR reviewer scoped to the architecture discipline only — new tradeoffs, module boundaries, reversibility, blast radius, quality-attribute effects, and novel dependencies. One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Docs Maker](./pr-review-docs-maker.md) — Execution-grade PR reviewer scoped to the documentation-quality discipline only — substantive README/docs/Diátaxis fit, doc drift vs. code, clarity, and doc alt-text/accessibility. One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Fixer](./pr-review-fixer.md) — Resolves review threads only inside the explicitly invoked [`pr-review-cycle`](../../../repo-governance/workflows/pr/pr-review-cycle.md); the single-pass `pr-review` never invokes it.
- [Pr Review Governance Maker](./pr-review-governance-maker.md) — Execution-grade PR reviewer scoped to the governance/rules-conformance discipline only — mechanical conformance to already-documented repo-governance/ conventions, naming/structure, ADRs, and spec-file presence. One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Instruction Maker](./pr-review-instruction-maker.md) — Execution-grade PR reviewer scoped to the instruction-decay discipline only — a framework/build-tool/package-manager/env-var/CI change in the diff not reflected in AGENTS.md/CLAUDE.md/.claude/, and instruction bloat (generic filler, not file length). One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Integrity Maker](./pr-review-integrity-maker.md) — Execution-grade PR reviewer scoped to the CI-gaming/test-integrity discipline only — weakened/skipped/narrowed tests, coverage-gaming, and missing regression tests. One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Logic Maker](./pr-review-logic-maker.md) — Execution-grade PR reviewer scoped to the business-logic/correctness discipline only — behaviour vs. domain intent plus Gherkin acceptance-criteria conformance across edge/error cases. One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Performance Maker](./pr-review-performance-maker.md) — Execution-grade PR reviewer scoped to the performance discipline only — concrete or likely performance regressions, hot-path changes, algorithmic-complexity growth, and resource (memory/IO/alloc) concerns. One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
- [Pr Review Scout Maker](./pr-review-scout-maker.md) — Planning-grade PR-review stage 0. It produces the risk tier, route-selected specialist set, shared-context brief, and probe class for each cycle; it never discovers or posts findings.
- [Pr Review Security Maker](./pr-review-security-maker.md) — Runs exact leak-only mode for the mandatory focused gate; broad semantic passes delegate those leak predicates and use its remaining security charter.
- [Pr Review Synthesis Maker](./pr-review-synthesis-maker.md) — Planning-grade PR-review coordinator — the eleventh pr-review-\*-maker agent and the mandatory synthesizer atop the nine sonnet-tier discipline specialists. Consumes the risk tier, specialist set, and shared PR/plan/full-diff context brief that pr-review-scout-maker assembles upstream each cycle (including the prior-cycle thread-resolution and human-dismissal read), then deduplicates, re-categorizes (owning the architecture-versus-correctness boundary), reasonableness-filters, and tool-verifies the specialists' raw findings before posting exactly ONE consolidated review via the GitHub Reviews API for pr-review-fixer to consume.
- [Pr Review Types Maker](./pr-review-types-maker.md) — Execution-grade PR reviewer scoped to the type-soundness discipline only — type-system soundness beyond what the compiler already enforces, across TypeScript, Rust, F#, and C#. Flags unsound type escapes (unjustified any/unknown, unexplained unsafe blocks, panic-prone unwrap/expect on fallible paths, null-forgiving-operator misuse, non-exhaustive match/switch), never a compile/build failure (already CI-gated) and never whether a well-typed function's behaviour is correct (pr-review-logic-maker's charter). One of nine discipline-scoped specialists feeding the pr-review-synthesis-maker coordinator; inherits pr-review-maker's hard rules verbatim, scoped to its own charter and SUPPRESS block.
