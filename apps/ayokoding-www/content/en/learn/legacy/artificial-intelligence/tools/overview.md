This section covers AI-powered coding agent tools — autonomous software that reads
codebases, runs commands, and completes engineering tasks on your behalf.

## Tools

| Tool                                                                                | Type                         | Key trait                                                           |
| ----------------------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------- |
| [Claude Code](/en/learn/artificial-intelligence/tools/claude-code/overview)         | AI coding assistant (CLI)    | Anthropic; whole-codebase understanding, natural-language interface |
| [OpenClaw](/en/learn/artificial-intelligence/tools/openclaw/overview)               | AI agent platform            | Local-first, JSON5 config, Lobster workflows, plugin ecosystem      |
| [Hermes Agent](/en/learn/artificial-intelligence/tools/hermes-agent/overview)       | Self-improving AI agent      | Closed learning loop, MEMORY.md persistence, 60+ tools              |
| [Pi Coding Agent](/en/learn/artificial-intelligence/tools/pi-coding-agent/overview) | Minimal coding agent harness | 4 primitive tools, TypeScript extensions, self-extensible           |

Each tool has two tutorial tracks:

- **By Example** — learn through heavily annotated real-world examples (95% coverage)
- **By Concept** — learn through narrative-driven concept explanations with annotated code
