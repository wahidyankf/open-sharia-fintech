Kali Linux is a Debian-based Linux distribution maintained by Offensive Security, purpose-built for
digital forensics and penetration testing. It ships with 600+ pre-installed security tools,
eliminating the manual setup required on general-purpose distributions.

## Available Content

- **[Quick Start](/en/learn/information-security/tools/kali-linux/quick-start)** - Install Kali in
  a virtual machine, navigate the desktop, and run your first network scan (0-30% coverage)
- **[Beginner](/en/learn/information-security/tools/kali-linux/beginner)** - Master
  reconnaissance, web application testing, and password auditing workflows with heavily annotated
  real-world examples (0-60% coverage)

## Key Features

- **600+ Pre-installed Tools** - nmap, Metasploit, Burp Suite, Wireshark, John the Ripper, and
  more — ready to use without additional setup
- **Rolling Release** - Continuously updated packages track the latest security tool versions
- **Custom Kernel** - Patched for wireless injection and USB boot support
- **Multiple Install Modes** - VM image, bare-metal ISO, Docker container, WSL2 on Windows
- **Kali NetHunter** - Mobile penetration testing platform for Android devices
