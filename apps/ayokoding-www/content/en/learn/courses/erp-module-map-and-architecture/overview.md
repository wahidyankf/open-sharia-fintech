## Why this exists

An ERP module map assigns a business capability and source ownership without fragmenting shared truth. It uses explicit integration contracts and derived read models at module seams.

## Silent-failure check

### What still balances while being wrong

Two modules can show the same balance while both accept writes to it. The observable signal is competing change histories without a single accountable source owner.
