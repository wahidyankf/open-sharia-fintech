ex-22 :: Run Checkhealth  (exercises co-01)

$ nvim --headless -u before/init.lua -c 'checkhealth vim.health' -c 'write! health-out.txt' -c 'qa!'
                                    " => on current Neovim, the base built-in checks live under the
                                    "    'vim.health' target name (bare `:checkhealth` with no argument
                                    "    would run this PLUS every other discoverable module, e.g.
                                    "    'vim.lsp', 'vim.treesitter', 'vim.pack')
