ex-37 :: Customize an LSP Server's Config Before Enabling  (exercises co-10)

$ nvim --headless -u after/init.lua scratch.lua \
  -c 'lua vim.wait(4000, function() return #vim.lsp.get_clients() > 0 end)' \
  -c "lua local c = vim.lsp.get_clients()[1]; print(vim.inspect(c.settings.Lua.diagnostics))" \
  -c 'qa!'
{
  globals = { "MY_CUSTOM_GLOBAL" }
}
                                    " => the attached client's LIVE settings table shows the exact
                                    "    Lua.diagnostics.globals value passed to vim.lsp.config -- direct
                                    "    proof the pre-enable customization reached the running server
