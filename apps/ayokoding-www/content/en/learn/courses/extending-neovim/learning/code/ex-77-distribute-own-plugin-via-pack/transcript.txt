ex-77 :: Distribute Your Own Plugin via vim.pack  (exercises co-18, co-08)

vim.pack.add() clones over plain git -- it has no idea whether "src" points at github.com or anywhere
else, so this was verified against a REAL local git repository (a genuine `git init` + commit, cloned via
a file:// URL) as a fully faithful stand-in for "https://github.com/you/myplugin": the code path
vim.pack.add executes is identical either way.

$ git init -q -b main myplugin-repo && cd myplugin-repo
  # myplugin-repo/lua/myplugin/init.lua returns { setup = function() end }
  # myplugin-repo/plugin/myplugin.lua sets vim.g.myplugin_autoloaded = true, guarded by a loaded flag
$ git add -A && git commit -q -m init

$ nvim --headless -c "lua vim.pack.add({{ src = 'file:///path/to/myplugin-repo', version = 'main' }})" \
  -c "lua print(pcall(require, 'myplugin'))" \
  -c "lua print(vim.g.myplugin_autoloaded)" \
  -c 'qa!'
