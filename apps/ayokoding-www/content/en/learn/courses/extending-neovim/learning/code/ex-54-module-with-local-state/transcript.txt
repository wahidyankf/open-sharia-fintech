ex-54 :: Module with Local (Closure) State  (exercises co-07)

$ nvim --headless -u after/init.lua \
  -c "lua local m = require('config.scratch'); print('first call:', m.increment())" \
  -c "lua local m = require('config.scratch'); print('second call:', m.increment())" \
  -c 'qa!'
first call: 1
second call: 2

                                    "    call picks up right where the first left off (2, not 1 again)
                                    "    because require() returned the SAME cached module table both times
