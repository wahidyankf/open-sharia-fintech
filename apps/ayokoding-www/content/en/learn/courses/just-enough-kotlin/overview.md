Kotlin makes absence explicit and keeps everyday JVM code compact. This primer gives you the small,
practical Kotlin surface needed to begin Android App Development:
values, nullability, functions, collections, classes, and a deliberately short coroutine preview.

It is a primer, not a Kotlin reference. Generics variance, delegated properties, reflection, flows,
channels, multiplatform configuration, and Android APIs are intentionally outside its boundary; the
Android course teaches platform work after this language foundation is secure.

## Prerequisites

This course has no earlier library-course prerequisite. Familiarity with classes and interfaces from
[Object-Oriented Programming Essentials](../object-oriented-programming-essentials/learning/overview.md) helps,
but every Kotlin example establishes its own context.

## What you will build

The learning track contains 78 small, annotated, copy-paste-ready examples. Standard-library examples
run with `kotlinc`; examples that use `kotlinx.coroutines` run in the shared Gradle project described
with the advanced examples. They advance from `kotlinc` and immutable bindings to sealed results and
structured concurrency. The final capstone combines a
nullable input, data class, collection pipeline, interface, and one suspending calculation in a
small command-line program.

Start with the [learning overview](./learning/overview.md), then use the [drilling track](./drilling/overview.md)
for recall after you have run the examples.
