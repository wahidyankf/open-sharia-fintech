# Interview-loop score sheet

Rate each dimension from 1 (missing or unsupported) to 4 (clear, evidence-backed, and within the
timer). Cite the actual artifact, not a feeling.

| Round            | Correctness / scope           | Communication              | Verification / evidence           |      Time / composure | Rating | Evidence and next action     |
| ---------------- | ----------------------------- | -------------------------- | --------------------------------- | --------------------: | ------ | ---------------------------- |
| Coding           | contract, pattern, invariant  | plan and complexity spoken | focused test result               |    timer and recovery | \_/4   | transcript line; one repair  |
| Take-home + live | brief answered, scope bounded | README and narration       | clean-checkout + checkpoint tests |      green increments | \_/4   | command output; one repair   |
| System design    | spine and deep dive           | diagram and summary        | bottleneck + two trade-offs       | adjusted to follow-up | \_/4   | walkthrough note; one repair |
| Behavioral       | six truthful STAR answers     | first-person, concise      | result and reflection             |       calm follow-ups | \_/4   | answer number; one repair    |

## Diagnosis

1. **Weakest round:** \_\_.
2. **Weakest observable dimension:** \_\_.
3. **Evidence:** cite a failed test, missing spine element, timer note, or answer number: \_\_.
4. **One concrete improvement:** run [specific prerequisite-course exercise or prompt] for [timer]
   and retain [specific proof] by [date or next rehearsal]: \_\_.
5. **Recheck condition:** the next loop is complete only when this row earns \_\_ with the named proof.

Do not average away the weakest round. The next action should be small enough to perform before the
next full loop and specific enough to verify.
