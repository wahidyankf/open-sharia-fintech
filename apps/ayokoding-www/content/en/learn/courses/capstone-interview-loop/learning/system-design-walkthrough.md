## Timed artifact

Give a 35-minute verbal walkthrough using [`design/walkthrough.md`](../design/walkthrough.md). Start
by clarifying scope and non-functional goals, then move through the established interview spine:
capacity estimate, high-level diagram, API and data outline, one deep dive, bottleneck, two trade-
offs, and closing summary.

The Mermaid diagram is a communication artifact, not an architecture course. For the underlying
depth, return to [System Design](/en/learn/courses/system-design); this loop exercises the
interview-facing rubric from [System Design Interview](/en/learn/courses/system-design-interview).

At the end, verify that the diagram is legible and that you can point to the bottleneck and both
trade-offs without adding requirements that the prompt did not ask for.
