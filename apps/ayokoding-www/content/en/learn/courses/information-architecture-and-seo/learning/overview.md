These 53 concepts progress from a reader's navigation model to crawler-visible markup and measurement.
Each example links to a course-owned semantic HTML, XML, text, JSON-LD, or decision artifact. Validate
the static artifacts locally; use live crawler and rich-results tooling only against a safe public test
surface.

## Concepts by Level

### Beginner (Examples 1–18)

The beginner lesson establishes information architecture, readable URLs, document landmarks, headings,
and text alternatives.

### Intermediate (Examples 19–38)

The intermediate lesson makes crawl and indexing controls explicit through sitemaps, robots rules,
canonical URLs, metadata, structured data, and social previews.

### Advanced (Examples 39–53)

The advanced lesson addresses localization, redirects, Core Web Vitals, internal linking, accessibility
overlap, measurement, and the integrated discoverability capstone.
