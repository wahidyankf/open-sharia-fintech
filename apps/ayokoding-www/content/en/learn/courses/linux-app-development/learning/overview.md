Run each source-matched example with `python3 main.py` from its directory; pytest examples run with `pytest main.py`. The examples progress from the Unix process contract to a packaged CLI and daemon.

## Route

- Beginner: process, streams, files, config, and child processes.
- Intermediate: signals, services, packaging, sockets, and test boundaries.
- Advanced: resilient CLI and daemon integration, distribution, and surveys.
- Capstone: an installable Unix-socket daemon and CLI.
