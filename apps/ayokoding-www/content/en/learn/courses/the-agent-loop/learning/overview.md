The learning track constructs a provider-agnostic, bounded loop in small Python examples: message state,
typed tool requests, dispatch, streaming, retries, stop conditions, and final answers. The next courses own
tool servers, durable context, permissions, and orchestration; this course owns the loop that connects them.
