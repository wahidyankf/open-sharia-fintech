The Agent Loop builds the read-evaluate-act control structure around a tool-calling model: observe a
response, validate an allowed action, execute it, append the result, and stop under explicit limits.

## Containment dispute

Whether this material belongs under context engineering, **harness engineering**, or both remains unresolved.
The public discussion on 2025-11-26 and the later framing on 2026-02-17 show competing useful boundaries:
context is an input to the loop, while the loop is a broader control harness. This course preserves that
dispute rather than renaming either discipline; it teaches the narrow executable control structure.
