This compact F# primer assumes [Functional Programming](../functional-programming/learning/overview.md)
and [Object-Oriented Programming Essentials](../object-oriented-programming-essentials/learning/overview.md).
It teaches immutable bindings, records, discriminated unions, exhaustive matching, pipelines, and
the small recursive expression trees that make a compiler evaluator natural.

## Scope boundary

This is a functional-first .NET on-ramp, not a full .NET framework course or the compilers course.
Use a current .NET LTS SDK; this page intentionally avoids a volatile SDK version.
