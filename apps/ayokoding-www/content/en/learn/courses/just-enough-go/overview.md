This primer makes you productive in Go before CSP-style concurrency: packages, values, functions,
collections, interfaces, error values, JSON, generics, idiomatic tooling, and only a concurrency
preview. It does not replace the next course's channel and cancellation depth.

## Prerequisites

- General programming fluency; Just Enough Python and Just Enough Bash provide useful contrasts.
- A terminal with a current stable Go toolchain and an editor with gopls support.

## Scope boundary

Use this course to learn Go's explicit surface and daily tool loop. Use CSP-Style Concurrency for
pipeline design, cancellation policy, worker pools, race analysis, and the Go memory model.

Start with the [learning overview](./learning/overview.md), then use [drilling](./drilling/overview.md).
