# Documentation

Welcome to the documentation for Open Sharia Enterprise (OSE), an open-source platform for
researching and building trustworthy, Sharia-compliant enterprise products. The repository is in
pre-alpha, so this is a good place to get oriented, run a product locally, and learn how the
platform is taking shape.

## Start here

New to OSE Public? Follow [Getting Started with OSE Public](./tutorials/getting-started-with-ose-public.md)
to prepare a supported development environment and run the OSE Platform website locally.

## Find the right kind of help

The documentation uses the [Diátaxis framework](https://diataxis.fr/) so you can choose material
that matches the question you have today.

- [Tutorials](./tutorials/README.md) — Guided, learn-by-doing journeys for using Open Sharia Enterprise.
  journey.
- [How-To Guides](./how-to/README.md) — Problem-solving guides for working safely and confidently in OSE Public
- [Reference](./reference/README.md) — Precise technical reference for the OSE platform, Nx workspace, quality gates, and supporting systems
  and its systems.
- [Explanation](./explanation/README.md) — Conceptual documentation for open-sharia-enterprise
  and engineering practices.

## Work with confidence

As an early engineer, use the repository guidance alongside the product documentation:

- [Documentation Conventions](../repo-governance/conventions/README.md) describe the project's file
  naming, linking, and organization standards.
- [Development Practices](../repo-governance/development/README.md) explain the tools, workflows,
  and quality practices used across the repository.

When you are ready to explore beyond the first local run, the tutorial's next steps point to the
product roadmap and the OSE public website's architecture.
