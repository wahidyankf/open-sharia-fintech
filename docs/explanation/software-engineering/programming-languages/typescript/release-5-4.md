# TypeScript 5.4 Release

TypeScript 5.4 is a documented migration milestone. Its relevant changes include preserved
narrowing in closures and the `NoInfer` utility type, both of which reduce workarounds in typed
application code.

Adoption is project-specific and remains reproducible through the exact package and lockfile pins.

**Upstream reference**: [TypeScript 5.4 release notes](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-4.html)
