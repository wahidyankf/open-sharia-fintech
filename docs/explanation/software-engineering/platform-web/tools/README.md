# Web Development Tools and Frameworks

These pages explain the web tools that appear in this repository. Read an application README first when you need to run or change a specific product; come here when you want the reasoning and shared conventions behind the framework.

## Choose a starting point

- [Next.js](./fe-nextjs/README.md) — application structure, routing, rendering, accessibility, and repository conventions for Next.js work.
- [React](./fe-react/README.md) — components, state, and user-interface practices used with TypeScript.

## A useful rule of thumb

Framework documentation can help you make a sound technical choice, but it does not decide product behaviour. Start by naming the user outcome and the boundary that owns it. Then use the relevant framework page to implement it in a way that fits the repository.
