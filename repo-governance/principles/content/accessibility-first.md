# Accessibility First

Design for **universal access from the start**. Accessibility is not an afterthought or optional feature - it's a foundational requirement that benefits everyone.

## Foundations

- [Vision Supported](./accessibility-first/vision-supported.md) — How the accessibility-first principle advances the Open Sharia Enterprise Vision of universal, inclusive access. Use when explaining why accessibility work matters to the project's mission, not just how to implement it.
- [What](./accessibility-first/what.md) — Defines what Accessibility First means in practice and why accessibility is built in from day one rather than retrofitted. Use when you need a concise definition of the accessibility-first requirement before diving into specifics.
- [Why](./accessibility-first/why.md) — Explains the universal-benefit, moral, and legal/professional rationale for prioritizing accessibility. Use when justifying accessibility work to stakeholders who ask why it is required.

## Applying the Principle

- [How It Applies](./accessibility-first/how-it-applies.md) — Concrete pass/fail examples of color accessibility, alt text, heading hierarchy, contrast, and semantic HTML. Use when implementing or reviewing content for compliance with color, alt-text, heading, contrast, or semantic-HTML accessibility rules.
- [Anti-Patterns](./accessibility-first/anti-patterns.md) — Common accessibility mistakes - color-only signaling, missing alt text, red-green combinations, and low-contrast text. Use when auditing content or diagrams for accessibility anti-patterns before publishing.
- [PASS: Best Practices](./accessibility-first/pass-best-practices.md) — Actionable best practices for accessible color palettes, testing, contrast verification, alt text, headings, and multi-cue design. Use as a checklist when producing or reviewing visual content, diagrams, or documents for accessibility.
- [Examples from This Repository](./accessibility-first/examples-from-this-repository.md) — Real examples from this repository showing accessible Mermaid diagrams, agent categorization, and document frontmatter. Use when looking for worked examples of accessibility principles applied within this repository's own content.
