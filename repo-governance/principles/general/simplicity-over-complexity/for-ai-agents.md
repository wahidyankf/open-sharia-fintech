# For AI Agents

All agents must follow this principle by:

1. **Define sufficiency before implementation** - identify the requested outcome and applicable
   repository rules
2. **Inspect existing mechanisms first** - add a dependency, abstraction, validator, automation,
   infrastructure path, or other lasting mechanism only for a concrete unmet need
3. **Avoid speculative scope** - do not generalize one-off work or anticipate unrequested features
4. **Verify proportionally and stop** - finish when the outcome is achieved and required checks pass
5. **Preserve mandatory safeguards** - tests, specifications, accessibility, security,
   documentation, governance propagation, and quality gates are part of sufficiency

See the "Principles Implemented/Respected" section in [AI Agents Convention](../../../development/agents/ai-agents/principles-implemented-respected.md#principles-implementedrespected) for how agents apply this principle.
