# Dynamic Collection References Convention

- [Dynamic Collection References Convention — Purpose, Principles, and Scope](./purpose-principles-and-scope.md) — Why hardcoded collection counts create a maintenance burden, which core principles this convention implements, and which collections and content types are in and out of scope. Use when deciding whether a numeric count you are about to write (agents, skills, conventions, principles, practices, workflows) is a dynamic collection this convention governs.
- [Dynamic Collection References — Standards (Rules 1-4)](./standards-rules-1-to-4.md) — The first four normative rules — never hardcode counts, layer descriptions must omit counts, index summaries must omit counts, and directory tree comments must omit counts. Use when checking a specific piece of prose (a sentence, a layer description, an index summary, or a directory tree comment) against the no-hardcoded-count rules.
- [Dynamic Collection References — Standards (Rules 5-7)](./standards-rules-5-to-7.md) — The remaining three normative rules — where counts are acceptable, index documents as the single source of truth for counts, and the numeric-sweep obligation on plan amendments. Use when deciding if a count is one of the acceptable exceptions, tracing a count back to its authoritative index, or sweeping a plan amendment for stale numeric prose.
- [Dynamic Collection References — Examples and Special Considerations](./examples-and-special-considerations.md) — Before/after conversion examples for common hardcoded-count patterns, plus edge cases like the index footer count and workflow/category count distinction. Use when converting an existing hardcoded count to a compliant reference, or when unsure whether a specific edge case (index footer, workflow count, category count) is exempt.
