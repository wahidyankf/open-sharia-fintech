# Corpus Census: Corpus Shapes

Part of the [Learning-Plan `syllabus/` Folder Convention](../learning-plan-syllabus.md). This and
[Corpus Census: Section Tiering](./corpus-census-section-tiering.md) together derive the section
tiers from measuring every existing course file in the three corpora that predate this convention,
not from intuition. Every number was measured by counting files under each plan's
`syllabus/courses/` directory, excluding `README.md` and `surgery.md` (a scope-contract document,
not a course).
