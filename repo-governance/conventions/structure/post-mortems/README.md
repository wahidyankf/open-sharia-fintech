# Post-Mortem Convention

- [Post-Mortem Convention: Principles, Purpose, and Scope](./principles-purpose-and-scope.md) — Why the post-mortem convention exists, the core principles it implements, and what it covers versus what it explicitly does not cover Read this when you need the rationale for post-mortems, or to confirm whether a topic falls inside or outside this convention's scope.

- [Post-Mortem Convention: No Secrets Rule, Diagrams, and Examples](./no-secrets-rule-diagrams-and-examples.md) — The hard no-secrets requirement for post-mortems, guidance for using accessible Mermaid diagrams, and worked filename and action-item table examples Read this when redacting sensitive values from a post-mortem, adding a diagram, or checking a filename or action-item table against PASS/FAIL examples.
