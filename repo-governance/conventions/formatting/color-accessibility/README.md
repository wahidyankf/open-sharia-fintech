# Color Accessibility Convention

- [Principles and Scope](./principles-and-scope.md) — Explains the accessibility and simplicity principles behind this convention plus what it covers and excludes. Use when you need to understand why this color accessibility convention exists or what falls inside/outside its scope.
- [Purpose](./purpose.md) — States why color accessibility matters and lists the five core rules for using color across the repository. Use when applying or auditing the five core color-accessibility rules before adding color to any content.
- [Verified Accessible Color Palette](./verified-color-palette.md) — Documents the eight-color verified accessible palette with hex, RGB, and HSL values and per-context usage recommendations. Use when picking specific hex codes for a diagram, indicator, or UI element that needs to be color-blind safe.
- [Colors to Avoid and Color Blindness Types](./colors-to-avoid-and-color-blindness-types.md) — Lists prohibited colors and combinations, and explains how each color blindness type perceives them. Use when checking whether a proposed color or color combination is unsafe for color-blind users.
- [Application Contexts: Emoji Indicators with Text Labels](./application-context-emoji-indicators.md) — Defines when standard emoji colors are acceptable because text labels always accompany them. Use when adding emoji status indicators such as criticality or pass/fail markers to confirm the color choice is acceptable.
- [Application Contexts: Mermaid Diagrams in docs/](./application-context-mermaid-diagrams.md) — Requires the verified accessible palette in Mermaid diagrams and gives implementation templates and best practices. Use when writing or reviewing a Mermaid diagram under docs/ that needs accessible color classDefs.
- [Application Contexts: AI Agent Color Categorization](./application-context-ai-agent-categorization.md) — Defines the colored-square emoji scheme used to categorize AI agents by role in agent index files. Use when assigning or reviewing a colored-square emoji for an agent definition in an agents README index.
- [Application Contexts: Emoji Squares, CSS, and Syntax Highlighting](./application-context-emoji-squares-css-syntax.md) — Covers accessible-palette guidance for colored square emoji plus future CSS custom properties and syntax-highlighting themes. Use when implementing CSS theme colors or syntax-highlighting palettes that must stay color-blind accessible.
- [WCAG Compliance Standards](./wcag-compliance-standards.md) — Specifies WCAG 2.2 AA contrast ratio requirements and lists the verified contrast ratios for each palette color. Use when verifying a color choice meets WCAG AA contrast requirements for text, UI, or graphical elements.
- [Dark Mode Considerations](./dark-mode-considerations.md) — Confirms the accessible palette works unchanged on both light and dark backgrounds and shows a worked contrast example. Use when testing whether a color renders with sufficient contrast in both light and dark mode.
- [Implementation Best Practices](./implementation-best-practices.md) — Gives five implementation rules covering hex codes, borders, multiple visual cues, documentation, and pre-publish testing. Use when implementing color in code or diagrams and you need the concrete do and don't rules to follow.
- [Testing Tools and Process](./testing-tools-and-process.md) — Lists the required color-blindness and contrast testing tools and walks through the five-step testing process. Use when running the accessibility testing process on new color-dependent content before publishing.
- [Verification Checklist](./verification-checklist.md) — Provides the pre-publish checklist confirming palette, borders, contrast, and testing requirements are all met. Use as a final checklist immediately before committing content that uses color.
- [Common Mistakes to Avoid](./common-mistakes-to-avoid.md) — Catalogs six common accessibility mistakes with wrong and correct Mermaid and CSS examples for each. Use when reviewing color usage for common accessibility mistakes such as red-green combinations or color-only coding.
- [Real-World Examples](./real-world-examples.md) — Shows a fully accessible Mermaid diagram and a fully inaccessible one, with a why breakdown of each. Use when you need a complete worked example contrasting accessible and inaccessible diagram color usage.
- [Research Sources and Citations](./research-sources-and-citations.md) — Cites the color science, accessibility standards, and color-blindness research underlying the verified palette. Use when you need the scientific or standards citation backing a claim made in this convention.
- [Related Conventions and Conclusion](./related-conventions-and-conclusion.md) — Links to related conventions and summarizes why following this color accessibility convention benefits everyone. Use when looking for related conventions to cross-reference or wrapping up review of this convention.
