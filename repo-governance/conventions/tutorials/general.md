# Tutorial Convention

Standards for creating effective, engaging, and pedagogically sound tutorials in the open-sharia-enterprise project. Tutorials are learning-oriented documentation under the Diátaxis framework, distinct from how-to guides, reference, and explanation. The sections below have moved into [`general/`](./general/) — read them in order for the full convention.
