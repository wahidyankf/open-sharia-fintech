# Tutorial Convention

- [Principles Implemented/Respected](./01-principles-implemented-respected.md) — Lists the Progressive Disclosure, No Time Estimates, and Accessibility First principles this convention implements.
- [Purpose](./02-purpose.md) — States that this convention establishes standards across all tutorial types and defines the Full Set Tutorial Package.
- [Scope](./03-scope.md) — Defines what the general Tutorial Convention covers and does not cover, and where it applies across the repository.
- [Overview](./04-overview.md) — Explains that tutorials are learning-oriented documentation and states the convention's purpose and scope of application.
- [Diátaxis Principles for Tutorials](./05-diataxis-principles-for-tutorials.md) — Defines what makes documentation a tutorial under the Diátaxis framework and contrasts tutorials with how-to guides, reference, and explanation.
- [Tutorial Structure Requirements: Required Sections (Items 1-2)](./06-tutorial-structure-required-sections-1-2.md) — Specifies the required title/metadata section and the introduction (hook) section that open every tutorial.
- [Tutorial Structure Requirements: Required Sections (Items 3-4)](./07-tutorial-structure-required-sections-3-4.md) — Specifies the required prerequisites section and the learning-objectives section that follow a tutorial's introduction.
- [Content Sections (The Learning Journey)](./08-tutorial-structure-content-sections.md) — Specifies the required content-section structure: concept introduction, explanation, demonstration, practice exercise, and checkpoint.
- [Tutorial Length and Splitting](./09-tutorial-length-and-splitting.md) — Defines the recommended tutorial length range and how to split an overlong tutorial into a progressive series.
- [Tutorial Structure Requirements: Required Sections (Items 6-7)](./10-tutorial-structure-required-sections-6-7.md) — Specifies the required Challenges section and the Summary-and-Next-Steps section that close every tutorial.
- [Section Flow Requirements](./11-section-flow-requirements.md) — Defines the progressive-complexity and smooth-transition requirements for how tutorial sections flow into each other.
- [Narrative Requirements: Story Arc and Progressive Scaffolding](./12-narrative-story-arc-and-scaffolding.md) — Defines the beginning/middle/end story arc and the progressive-scaffolding technique for tutorial narrative.
- [Narrative Requirements: Voice, Perspective, and Transitions](./13-narrative-voice-and-transitions.md) — Defines the required teacher voice and perspective, plus the transition patterns used to connect tutorial sections.
- [Engagement Techniques](./14-narrative-engagement-techniques.md) — Defines storytelling, motivational-element, humor, and relatable-example techniques for keeping learners engaged.
- [Diagrams (Mermaid)](./15-visual-diagrams-mermaid.md) — Defines when to use Mermaid diagrams in a tutorial, required diagram elements, and diagram types by use case.
- [Visual Completeness Requirements: Code Examples and Visual Aids](./16-visual-code-examples-and-visual-aids.md) — Defines requirements for runnable code examples and for visual aids (timelines, tables, comparisons) that make abstract tutorial concepts concrete.
- [Screenshot Requirements (If Applicable)](./17-visual-screenshot-requirements.md) — Defines when tutorials should include screenshots and the resolution, annotation, and alt-text requirements for them.
- [Hands-On Elements Requirements: Practice Exercises](./18-hands-on-practice-exercises.md) — Defines the frequency, difficulty, and structure requirements for practice exercises placed after each major tutorial section.
- [Hands-On Elements Requirements: Challenges and Interactive Elements](./19-hands-on-challenges-and-interactive-elements.md) — Defines the end-of-tutorial Challenges structure and the interactive elements (checkpoints, reflection, prediction questions) used throughout.
- [Real-World Relevance](./20-hands-on-real-world-relevance.md) — Defines the requirement that every major tutorial concept connect to a real-world case study, industry context, or decision framework.
- [Technical Standards](./21-technical-standards.md) — Defines mathematical-notation (LaTeX), code-example, file-organization, and accessibility technical standards for tutorials.
- [Validation Criteria: Structure, Narrative, and Visual Validation](./22-validation-structure-narrative-visual.md) — Lists the structure, narrative, and visual validation checklist items that docs-tutorial-checker verifies on a tutorial.
- [Validation Criteria: Hands-On and Technical Validation](./23-validation-hands-on-and-technical.md) — Lists the hands-on and technical validation checklist items that docs-tutorial-checker verifies on a tutorial.
- [Content Quality Validation](./24-validation-content-quality.md) — Lists the accuracy, completeness, clarity, and engagement validation checklist items that docs-tutorial-checker verifies on a tutorial.
- [Anti-Patterns: Reference Material Through Assuming Too Much Prior Knowledge (1-4)](./25-anti-patterns-reference-material-through-prior-knowledge.md) — Documents the first four tutorial anti-patterns: reference material disguised as tutorial, goal-oriented framing, and assuming too much prior knowledge.
- [Anti-Patterns: No Hands-On Practice Through No Story or Context (5-8)](./26-anti-patterns-no-hands-on-through-no-story.md) — Documents anti-patterns 5 through 8: missing hands-on practice, missing visual aids, incorrect LaTeX delimiters, and sudden difficulty jumps.
- [Anti-Patterns: Missing Prerequisites Through Inconsistent Voice or Tone (9-12)](./27-anti-patterns-missing-prerequisites-through-inconsistent-voice.md) — Documents the final four anti-patterns: missing prerequisites, missing checkpoints, unexplained solutions, and inconsistent voice.
- [Examples and Templates](./28-examples-and-templates.md) — Provides a pointer to exemplary tutorials and a complete fill-in-the-blank tutorial template covering frontmatter through the first section.
- [Tutorial Template Reference: Challenges, Summary, Next Steps, and Further Resources](./29-template-reference-challenges-summary-next-steps.md) — Continues the tutorial template reference with its Challenges, Summary, Next Steps, and Further Resources sections.
- [Related Conventions and External Resources](./30-related-conventions-and-external-resources.md) — Links to the conventions this document builds on and to external learning-theory, Diátaxis, and technical-writing resources.
