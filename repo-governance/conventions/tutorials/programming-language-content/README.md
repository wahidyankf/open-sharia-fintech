# Programming Language Content Standard

- [Principles, Purpose, and Scope](./principles-purpose-and-scope.md) — Explains the core principles behind the Programming Language Content Standard, why it exists, and exactly which content and locations it applies to. Use when you need to understand why this standard exists, what it guarantees, or whether a given piece of content falls inside its scope.
- [Universal Directory Structure](./universal-directory-structure.md) — The mandatory directory tree every programming language must follow on ayokoding-www. Use when scaffolding or auditing a language's content folder/file layout.
- [Weight System Explanation](./weight-system-explanation.md) — How to compute Hugo navigation weights for programming language content, based on directory depth and per-parent weight ranges. Use when assigning or auditing the `weight` frontmatter value for a folder's `_index.md` or a content file in the programming-language content tree.
- [Weight System Notes and Cookbook Relocation](./weight-system-notes-and-cookbook-relocation.md) — Wraps up the weight-system explanation and documents the cookbook's move from how-to/cookbook.md into the tutorials/cookbook/ folder. Use when you need the closing notes on the weight system, or when migrating a language's cookbook from the deprecated how-to/cookbook.md location.
- [Cookbook Weight Resets and Summary](./cookbook-weight-resets-and-summary.md) — Shows how sibling category folders independently reset their child weights, and summarizes the full level-based weight system. Use when you need to confirm that two sibling files can safely share the same weight number, or want a one-glance summary of the weight system.
- [Coverage Philosophy](./coverage-philosophy-scale-and-initial-levels.md) — Introduces the 0-95% proficiency scale and defines the Initial Setup and Quick Start coverage levels, the first two components of the Full Set Tutorial Package. Use when deciding what percentage of language knowledge a piece of content should target, or when writing the Initial Setup or Quick Start tutorial.
- [Coverage Levels: Beginner Through Advanced](./coverage-levels-beginner-through-advanced.md) — Defines the Beginner, Intermediate, and Advanced coverage levels for programming language tutorials, from 0% to 95% knowledge depth. Use when writing or reviewing the Beginner, Intermediate, or Advanced tutorial for a programming language.
- [Coverage Levels: Cookbook and By-Example Tracks](./coverage-levels-cookbook-and-by-example.md) — Defines the two parallel-track coverage levels: the recipe-based Cookbook and the code-first By Example track for experienced developers. Use when writing or reviewing a language's Cookbook or By Example content, or deciding whether new content belongs in one of these parallel tracks.
- [Pedagogical Requirements](./pedagogical-requirements.md) — Defines the mandatory content patterns every tutorial, how-to guide, and explanation document must follow for programming language content. Use when authoring or reviewing a tutorial, how-to guide, or explanation document for programming language content, to check it against the mandatory patterns.
- [Content Completeness Criteria](./content-completeness-criteria.md) — Defines the five mandatory components plus supporting documentation a programming language needs to have a complete Full Set Tutorial Package. Use when assessing whether a programming language's content is complete, or when planning what remains to reach Full Set status.
- [Quality Metrics](./quality-metrics.md) — Quantitative line-count and diagram benchmarks plus qualitative requirements that all programming language content must meet. Use when measuring a piece of programming language content against its minimum/target/exceptional length benchmarks or checking qualitative compliance.
- [Language Consistency, Density, and Validation](./language-consistency-density-and-validation.md) — Distinguishes universal from customizable content elements, sets content-density ratios, and defines the validation process across creation, publishing, and post-publishing. Use when deciding whether a piece of content should be identical across languages or language-specific, sizing a section relative to the Beginner tutorial, or running the validation pipeline.
- [Replication, Benchmark Examples, and Related Resources](./replication-benchmark-examples-and-related-resources.md) — The step-by-step formula for adding a new programming language, a summary of the three benchmark language implementations, and links to related conventions and guides. Use when starting content for a brand-new programming language, looking for a reference implementation to model, or navigating to a related convention or how-to guide.
- [Highest Standards Reference](./highest-standards-reference.md) — Identifies Elixir as the current highest-standard reference implementation, documents alternative-excellence languages, and lists known quality gaps even in the benchmark. Use when you need the single best existing example to model new or improved content on, or want to know the known gaps that remain even in the highest-standard content.
