# Step 6: Write and Subject-Scoped Tidy

The rule is written, and every other surface stating its subject is brought into agreement. The
sweep is bounded by the subject recorded at Step 2 — nothing wider.

## Write

Write the normalized statement into the destination decided at Step 4, matching the destination
document's existing voice, density, and structure. A rule that reads as a foreign insertion invites
a later editor to "clean it up" into something weaker.

## Tidy the Subject

Enumerate every surface stating the subject — not only the ones the conflict scan surfaced — and
for each, apply exactly one outcome:

| Situation                                    | Outcome                                 |
| -------------------------------------------- | --------------------------------------- |
| States the rule identically                  | Delete, leave a link to the new home    |
| States it partially or in weaker words       | Amend to match the normalized statement |
| Superseded per Step 3                        | Retire, with the supersession recorded  |
| States an adjacent rule that now reads oddly | Amend for coherence, never for scope    |

Fix the **class**, not the sites a single search happened to name. Enumerate every surface per
directory and record a verdict for each, including "no change needed" — an unexamined surface and
an examined-and-unchanged surface are indistinguishable afterwards, and the difference is the whole
point of the sweep.

## Reindex

Any file created, renamed, or deleted updates its parent index with a full annotation, and the
governance index above that. An index entry that lists a child without describing it fails the
completeness requirement, and a child missing from its index is unreachable.

## Regenerate

Where the write touched a source that mirrors elsewhere, regenerate the mirrors and let them land
in the same commit. Never hand-edit a mirror. Where the write touched a declaration, revalidate the
declaration's schema before moving on.

## Budget

Measure the word count of every file this step touched. A single added table row can cross a
ceiling, and the sanctioned remedy is always a split with an annotated index — never compression
that drops substance, and never a raised threshold.

## Ledger

Record every path on the file-touch ledger opened at Step 1, including deletions.
