# Cycle Non-Credit Record

A posted cycle whose scout pin stops matching the live PR head still consumes its ordinal, but it
cannot receive clean or done credit. The orchestrator posts exactly one top-level PR comment with
this block immediately after either mismatch boundary, including when the review posted zero
finding threads:

```html
<!-- ose-pr-review-cycle-credit:v1
{"cycle":5,"review_head":"<40-char scout SHA>","observed_head":"<40-char live SHA>",
 "boundary":"post-review|post-ci","credit":"ineligible"}
-->
```

The comment ends with the canonical `Generated by AI` footer. It is deliberately independent of
finding dispositions: post-CI drift can happen after every thread is settled, and a zero-finding
review has no thread. A pre-post mismatch creates neither a cycle review nor this event.

Hydration reads these events with the cycle reviews. Exactly one event may name a given
`cycle`/`review_head`; malformed, duplicate, conflicting, or orphaned events stop reconciliation.
An `ineligible` cycle counts toward the configured ceiling, receives no clean/done credit, and
breaks the consecutive-clean streak. Any underlying claim closed as `stale-cycle-only` remains
eligible for fresh-head review; the cycle event does not dismiss findings.

Top-level comments remain forbidden for finding replies. This event is cycle state, not review
thread state, and only the orchestrator posts it.
