# Containers — ts-env-loader

C4 Level 2 containers for `ts-env-loader`.

`ts-env-loader` ships as a single container: a TypeScript constants-and-function package
(`@open-sharia-enterprise/ts-env-loader`) consumed at process-startup time by every Next.js and
Vite app in the workspace. It has no separate deployable runtime of its own.

See [container.md](./container.md) for the C4 container diagram placeholder.
