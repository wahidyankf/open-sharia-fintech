# web-ui-token — Product Overview

`web-ui-token` provides the structural design tokens (color, spacing, radius, typography)
consumed by `web-ui` and every TypeScript frontend in the workspace, via both a TypeScript module
(`colorTokens`, `radius`, `spacing`, `typography`) and CSS custom-property sheets
(`src/tokens.css` plus per-app brand overlays: `organiclever.css`, `ose.css`,
`ayokoding.css`).

See [README.md](./README.md) for C4 L1 product framing.
