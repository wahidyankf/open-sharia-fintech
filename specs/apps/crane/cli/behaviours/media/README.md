# crane — cli/behaviours/media

Gherkin scenarios for crane-cli media and visual element checks.

Features in this domain:

- `table-check.feature` — table extraction and formatting validation
- `figure-check.feature` — figure and image reference validation
- `mermaid-validate.feature` — Mermaid diagram syntax validation
- `ocr-quality.feature` — OCR output quality checks

for the canonical purpose of this folder.
