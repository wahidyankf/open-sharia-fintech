diagnostic:

`string report.Mappings`. The fix parses the flag into an `int` and compares
numerically, so the `string` call disappears and a non-numeric argument is now
CLI misuse (exit 2) instead of a silent count mismatch.

The local analyzer does not reproduce the diagnostic. Re-running the exact
lint command with the pre-fix expression restored still reported
