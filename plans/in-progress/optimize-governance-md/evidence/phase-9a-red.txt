FR-1.10 `governance-word-budget` gate block):

  governance-word-budget:
    surfaces:

  - repo-governance/conventions/formatting/linking.md — staged/added

  $ git add repo-governance/conventions/formatting/linking.md repo-config.yml
  $ git status --short
  A  repo-config.yml
  A  repo-governance/conventions/formatting/linking.md
  ?? repo-governance/development/          (ai-agents.md unstaged)

  $ rhino-cli gate run --surface=pre-push
  Running gate governance-word-budget
  WORD BUDGET: 1 finding(s)
    [FAIL] repo-governance/development/agents/ai-agents.md — repo-governance/development/agents/ai-agents.md is 664 words (over 500-word fail limit); apply progressive disclosure — see repo-governance/principles/content/progressive-disclosure.md

(repo-governance/development/agents/ai-agents.md), even though only an
unrelated file (linking.md) was staged. This proves FR-1.12: a matched
trigger validates the whole covered tree, not just the changed files.
