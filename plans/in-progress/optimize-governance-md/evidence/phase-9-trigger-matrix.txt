Phase 9b-2 — proving `governance-word-budget` / `governance-readme-completeness`
path-gating fires and skips correctly, on both `pre-push` and `ci`
====================================================================

Context
-------
A trigger list that never fires is worse than no gate — it reads as green. This
proves both directions on both surfaces for the two gates Phase 9 armed, per
the falsifiability rule that an acceptance clause must be checkable in both
directions.

Method
------
Isolated throwaway git fixture (not the real ose-public repo), exercised via
the real CLI binary (`apps/rhino-cli/target/release/rhino-cli`) end-to-end.
Re-recorded 2026-08-15 under the six mandatory isolation layers required by
[Git Fixture Isolation](../../../../repo-governance/development/quality/git-fixture-isolation.md)
— the original transcript (pre-2026-08-15) ran `git reset && git clean -fd`
with no `GIT_DIR`/`GIT_CEILING_DIRECTORIES`/`GIT_CONFIG_GLOBAL`/`GIT_CONFIG_SYSTEM`
and no pre-write escape guard, which a PR review correctly flagged: the layers
were absent, even though no escape actually occurred (the post-run tree was
clean both times).

Env-var isolation preamble (all `git` and `rhino-cli` invocations below run
with this environment; verbatim, not paraphrased):

  GIT_DIR=<fixture>/.git
  GIT_CEILING_DIRECTORIES=<fixture>
  GIT_CONFIG_GLOBAL=/dev/null
  GIT_CONFIG_SYSTEM=/dev/null

`GIT_WORK_TREE` is deliberately **not** set (Standard 2's plain-write-sequence
exception — CWD is already pinned to the fixture root for every command, and
the escape guard below relies on `--show-toplevel` resolving from `GIT_DIR`
rather than echoing a set `GIT_WORK_TREE`).

Escape guard (Standard 4): before every write (`init`, `config`, `add`,
`commit`, `reset --hard`, `clean -fd`), `git rev-parse --show-toplevel` was
asserted to canonicalize to the fixture root under the same four env vars.
The guard ran clean on every call this session — no trip, no fallback to
ambient discovery.

Standard 6 (process rule): the fixture was built, exercised, and destroyed
from this session's scratchpad directory, never diagnosed against or from the
primary `ose-public` checkout.
