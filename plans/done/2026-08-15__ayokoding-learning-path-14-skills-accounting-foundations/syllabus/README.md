# Accounting Foundations Syllabus

**Custodian**: ayokoding-learning-path-14-skills-accounting-foundations

This corpus specifies the shared eleven-course accounting foundation used by both skills paths. It teaches accounting reasoning and review controls; it does not ask learners to build an accounting system.
