# ERP Availability and Reservations

**Custodian**: ayokoding-learning-path-18-skills-erp-enterprise-depth

## Outcome

Availability is a promise policy built from on-hand, inbound, allocated, and safety-stock states.

## Prerequisites

- `inventory-and-warehouse-management`
- `production-planning-and-mrp`

## Format

By Example

## Concepts and examples

- State the governing business event and canonical record.
- Compare a normal path with a safe exception path.
- Reconcile the result to retained evidence and accountable approval.

## Practice and assessment

Decide whether a transfer order should reserve, allocate, or merely forecast stock.

A learner passes by explaining the policy, state transition, control, and evidence for a synthetic case.
